# Maria & Alexander — Digital Wedding Invitation

A digital wedding invitation web application featuring a click-to-open envelope hero section animated with **Rive**, followed by an editorial reveal of the wedding invitation card for **Maria Elizabeth Vance & Alexander Cole Wright** at **Villa Balbiano, Lake Como, Italy**.

**Design by JunaidStudios**

---

## ✨ Features

- **Interactive Rive Envelope Hero**: Full-viewport centered hero section with responsive canvas scaling, dynamic state machine input discovery, and paper-rustle audio synthesized via the Web Audio API.
- **GSAP Editorial Drift Reveal**: Graceful staggered entrance animations for the revealed invitation card.
- **High-Resolution Photography**: Bespoke Italian wedding editorial photography, arched portrait frames, Villa Balbiano destination spotlight, and lakeside candlelit banquet showcase.
- **Interactive Lightbox Viewer**: High-definition full-screen image viewer with blurred backdrop, captions, and keyboard accessibility (`Esc`, `Enter`, `Space`).
- **Live Wedding Countdown**: Real-time days, hours, minutes, and seconds countdown to October 24, 2026.
- **Celebration Itinerary**: Welcome reception, botanical garden ceremony, sunset lake cruise, and dinner dancing.
- **RSVP Dialog & Calendar Integration**: Interactive response form with feedback toast and Google Calendar export.
- **Romantic Audio Synthesizer**: Ambient romantic background music synthesized with Web Audio API.
- **Replay Control**: Allows guests to re-experience the envelope opening animation at any time.

---

## 🛠️ Tech Stack

- **Framework**: [Vite](https://vitejs.dev/)
- **Core**: Vanilla JavaScript (ES Modules) & HTML5
- **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid, Glassmorphism)
- **Animation**: [@rive-app/canvas](https://rive.app/) & [GSAP](https://greensock.com/gsap/)
- **Celebration FX**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio**: Web Audio API (zero external audio file dependencies)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jhonydon786/wedding-invitation.git
   cd wedding-invitation
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
